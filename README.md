# Excel-helper

## 项目简介

本项目利用开源大语言模型，打造智能Excel操作助手。用户通过自然语言即可完成数据查询、统计分析、图表生成及公式编写等复杂任务，无需记忆函数。项目旨在降低数据操作门槛，提升办公效率，让每个人都成为数据分析师。核心优势：本地部署保障数据安全，开源模型降低使用成本，灵活适配多种业务场景。
